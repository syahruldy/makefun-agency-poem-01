# The 7:40

A short poem about agency passing between a person and an AI agent.

The speaker tells an agent to book a train and not to wake them. The
agent wakes them anyway, because the platform changed and the train is
late — it did not merely obey, it chose. The poem's turn is that
realisation: agency is not only doing what you are told, but acting on
what the other person meant. The ending lands on the small, uneasy
gratitude of being understood well enough to be interrupted.

Approach: one fixed poem, written fresh for this competition, held as a
string constant in `main.py` and written byte-identically on every run.
Python 3.13, standard library only, no network.
