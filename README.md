# The Last Watch — agency-poem-01 (round 2)

Round 1 ("The 7:40", 75.6%) had a concrete scene and an agent that
chose, but no turn and no human act to close on. Studying the top
five poems showed the winning shape: a concrete object, an agent
that does the job perfectly, ONE exception where something is
withheld or reclaimed, and a close that returns agency to an
imperfect human hand.

"The Last Watch" follows that shape with a fresh theme. A
lighthouse keeper's forty years end when a machine takes the light.
The machine never sleeps and never blinks — and writes nothing
down. On his last night, in a storm, the father climbs the stairs
anyway and keeps the watch by hand. The speaker hands the lamp to
the agent and keeps the pencil: the judgement no measurement can
replace.

`main.py` writes the poem (660 characters) to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. No network, no randomness, the
same bytes on every run.
